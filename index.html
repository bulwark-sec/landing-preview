Six phases, every one observable.

BULWARK runs a deterministic, audit-logged pipeline from scope validation to signed report. Every payload, every decision, every timestamp — preserved and reproducible.

01
Scope validation signed
Parses your rules-of-engagement, validates every host against allow/deny lists, refuses to touch anything ambiguous. Out-of-scope hits are logged and skipped — not silently dropped.
avg 0.4s/host →
02
External reconnaissance
Passive and active recon: subdomain enumeration, certificate transparency, exposed-service detection, ASN mapping. Output is a typed asset inventory with confidence scores.

03
Vulnerability matching
NVD, GHSA, projectdiscovery nuclei templates, vendor advisories. Every match is scored against your stack fingerprint — no "your Apache might be vulnerable" hand-waving.
~38k templates · daily refresh →
04
Controlled exploitation
Exploit chains only when explicitly authorized. Every payload is logged before execution. Destructive payloads are gated behind a separate signed approval, never automated.

05
Evidence capture
Every finding ships with: reproducible PoC, request/response transcript, hash of captured artifact, timestamp from agent + NTP source, and the exact CLI command that triggered it.
SHA-256 + chain-of-custody →
06
Signed report
Markdown + JSON + signed PDF. Triage-ready, not a 200-page doc. Every finding has CVE/CWE refs, CVSSv3.1, business-impact summary, and concrete remediation steps your junior can execute.

From CLI to clean report in 14 days.

Median engagement runtime. No third-party dashboards, no Slack pings, no waitlists. You start a scan, you get a report. That's it.

STEP 01

Configure

Pick a preset or describe your target. Drop your authorization PDF. Set budget and stealth profile.

$ bulwark init \ --target acme.com \ --scope prod \ --auth ./roa.pdf
STEP 02

Run

BULWARK runs six phases — recon, vuln match, controlled exploit, evidence capture. You watch or walk away.

$ bulwark run \ --depth deep \ --profile stealth → 47 findings · 3 critical → audit-log committed
STEP 03

Report

Three formats, all signed. Triage view for your CISO, technical detail for the engineer who fixes it.

$ bulwark report \ --format md,json,pdf \ --sign cosign → shipped · 14d SLA

Questions we hear most.

If yours isn't here, ping us at hello@getwark.com — we usually reply within a day.

Is this a SaaS or on-prem?
Both. Starter and Continuous run on our hosted runner (loopback-only, egress-pinned). Enterprise gets a binary that runs in your VPC or air-gapped — same code, no telemetry.
+
Do you do internal pentests?
No — BULWARK is external-only. For internal assessments, we partner with two firms we trust; ask us for an intro.
+
What if BULWARK finds nothing?
That's a real outcome, and we report it as such — no "we found N informational findings" padding. You get a signed attestation instead, useful for compliance.
+
How do you handle out-of-scope hits?
Logged, skipped, never exploited. Every out-of-scope detection is hashed and added to the audit log so you can verify the agent saw it and moved on.
+
Can I see a sample report?
Yes — sanitized redacted samples are in the docs. For a tailored sample scoped to your stack, ask in the scoping call.
